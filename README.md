## 🎨 Sobre o Projeto

O **Pixel Chrono** é uma aplicação web leve desenvolvida com HTML5, CSS3 e JavaScript puro. O objetivo foi criar uma interface retrô inspirada em RPGs e arcades clássicos, contando com fontes pixeladas, botões com efeito 3D em camadas e um esquema de cores imersivo.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando apenas tecnologias nativas da web, sem frameworks pesados:

* **HTML5** — Estruturação semântica.
* **CSS3** — Estilização personalizada, layout flexbox, fontes do Google Fonts (`Press Start 2P`) e efeitos de sombra pixelados (`box-shadow`).
* **JavaScript (ES6+)** — Lógica do cronômetro, manipulação de tempo (`setInterval` / `clearInterval`) e manipulação do DOM.
